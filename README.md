# SSBP-and-multiomics
Core code for the article "Gut microbiota-derived metabolite isovalerylcarnitine modulates salt sensitivity of blood pressure and incident hypertension"

Due to privacy regulations, the complete human data from the two trials and cohorts are available only under restricted access. To allow verification of the analytical code used in this study, we uploaded a randomly selected subset of participants (20%) (species.abundance, alldata.mst, chgdata.mst, alldata.gst, chgdata.gst, cohort1-cohort5). Consequently, results derived from these data do not reflect the true results reported in the article.

In addition, all data from the animal experiments have been uploaded (alldata.wistar, alldata.dahl.bp, alldata.dahl.artery, alldata.dahl.others, alldata.dahl.oral, pharmadata, alldata.sd), and the results generated from these data are consistent with those reported in the article.

No standalone software was developed in this study. All statistical analyses were performed using R (version 4.3.1; R Foundation for Statistical Computing, Vienna, Austria). The core scripts are provided in the file “Core codes.R”. All required R packages can be installed from the Comprehensive R Archive Network (CRAN): https://cran.r-project.org/.
